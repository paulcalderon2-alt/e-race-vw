# e-Race VW Group

Sitio estático preparado para GitHub Pages.

## Publicación
1. Crea un repositorio público en GitHub.
2. Sube a la raíz: `index.html`, `404.html`, `styles.css`, `app.js` y `.nojekyll`.
3. En **Settings > Pages**, selecciona **Deploy from a branch**.
4. Selecciona `main` y `/(root)`.
5. Abre la URL de GitHub Pages y usa **Crear carrera**.

El QR se construye en el navegador usando la URL pública actual, por lo que funciona también cuando el proyecto está publicado como `usuario.github.io/nombre-repositorio/`.

## Requisitos
- Navegador moderno con JavaScript.
- Acceso a internet para cargar PeerJS y QRCode desde CDN.
- El anfitrión debe mantener abierta la pestaña durante la partida.
